# Строй·Гайд

**Гитара в любом строе: 157 строев — и отдельный гайд к каждому.**

Одностраничное приложение целиком в одном `index.html`: без сборки на сервере, без зависимостей,
без интернета. Открыл файл — работает; выложил на GitHub Pages — работает так же.

🌐 **Сайт:** `https://<твой-ник>.github.io/stroy-guide/`

---

## Что внутри

| Раздел | Что делает |
|---|---|
| **Гриф** | гриф под выбранный строй и тонику, гаммы/лады, боксы, клик по нотам — звучание |
| **Гайд строя** | что сохраняется из привычных форм, аккорды и позиции этого строя, калибры струн, план перехода |
| **Стили** | 8 стилей (блюз, джаз, рок, трэш, мелодик-дет…) с редактируемыми ритм-сетками |
| **Подбор** | мастер из 4 вопросов → 3–5 строев с объяснением «почему именно эти» |
| **Все строи** | каталог 157 строев: стандартные, half-step, drop, open/modal, 7 и 8 струн, бас |
| **Соло-лаборатория** | мотив → 6 превращений → соло на 4/8/16 тактов с разбором по тактам и приёмами |
| **Аккорды / Ритм** | соло по аккордовым тонам текущей прогрессии, метроном, тэп-темп |
| **Лупер** | запись клавишами и мышью, квантайз, свинг, две свои дорожки A/B, слоты A–D, экспорт **WAV / MIDI / таб**, перенос лупа файлом или ссылкой |
| **Практика** | план занятий и печать гайда по страницам |

Звук синтезируется через Web Audio API — никаких сэмплов и внешних файлов.
Настройки и черновики хранятся в `localStorage` браузера.

## Быстрый старт

Просто открой `index.html` в браузере. Всё.

Если хочешь локальный сервер (нужен для ссылки «Поделиться» и корректного `localStorage`):

```bash
python3 -m http.server 8000 --bind 0.0.0.0
# → http://localhost:8000
```

## Сборка

`index.html` — **результат сборки**, руками его править не нужно. Весь код лежит в `src/`:

```bash
python3 build.py        # src/* → index.html
```

| файл | назначение |
|---|---|
| `src/style.css` | все стили |
| `src/body.html` | разметка |
| `src/core.js` | утилиты, состояние, навигация |
| `src/tunings.js` | база 157 строев |
| `src/genres.js` | стили и риффы |
| `src/guide-core.js`, `src/guide-html.js` | генерация гайда строя |
| `src/solo.js` | соло-лаборатория |
| `src/engine.js` | звуковой движок, гриф, аккорды |
| `src/styles.js` | раздел стилей и ритм-сетки |
| `src/picker.js` | мастер подбора |
| `src/looper.js` | лупер, дорожки, WAV/MIDI, перенос |

```bash
  && node tools/picker-test.js && node tools/tracks-test.js && node tools/solo-test.js
```

Эталонные цифры: строев 157 · midi 342 · io 83 · picker 2583 · tracks 94 · solo 5885 — везде 0 провалов.

Браузерные проверки (консоль, клики, мобильная вёрстка 390px, печать):

```bash
npm i && npx playwright install chromium && npx playwright install-deps chromium
python3 -m http.server 8000 --bind 0.0.0.0 &   # в другом терминале
npm run check
```

## Публикация на GitHub Pages

Репозиторий уже готов к публикации: `index.html` лежит в корне, `.nojekyll` отключает Jekyll.

1. **Settings → Pages**
2. **Source:** `Deploy from a branch`
3. **Branch:** `main`, папка `/ (root)` → **Save**
4. Через минуту сайт доступен по адресу `https://<ник>.github.io/stroy-guide/`

Обновление сайта = новый коммит в `main`. Пересобрал `index.html` → запушил → через минуту на сайте.

## Технологии

Чистые HTML + CSS + JavaScript, Web Audio API, Canvas/SVG, `localStorage`.
Ноль рантайм-зависимостей; Node.js и Playwright нужны только для тестов.
